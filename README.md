### 🧭 How I Work

| Principle | In practice |
|---|---|
| **Automate the boring** | Every repeatable deploy, cert renewal and health check lives in a pipeline or cron, not a wiki page |
| **Measure before tuning** | Prometheus + Grafana first, then optimize latency/cost with real numbers |
| **Secure by default** | Least-privilege IAM, WAF + rate limits at the edge, short-lived stream tokens |
| **Test under load** | k6 spike tests before peak traffic, not after the incident |
