### 🧭 How I Work

| Principle | In practice |
|---|---|
| **Automate the boring** | Deploys, cert renewals and health checks live in pipelines, not in someone's memory |
| **Security first** | Least-privilege IAM, hardened servers, WAF + rate limits at the edge (a habit from threat analysis) |
| **Measure before tuning** | Dashboards first, then optimize latency and cost with real numbers |
| **Test under load** | Spike-test before peak traffic, not after the incident |
